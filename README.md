## About this project

**StreamLine Spotlight** is a product concept I developed across six in-class modules, taking a raw problem all the way from strategic discovery to a launch-ready go-to-market plan. Each module had one or two lab exercises that produced a concrete deliverable; those deliverables feed directly into the final presentation deck.
